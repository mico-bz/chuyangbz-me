ISA / 指令集

每 tick 最多 14 条 · 24 条上限
SENSE a 读传感器写入 R a: 0最近食物方向 1前 2右 3左 4能量 5对手距 6随机 7常数1 JMP a 相对跳转 a-3 JZ a R==0 时相对跳转 TURN a 直接设定朝向 a%4 (0上 1右 2下 3左) MOVE 朝当前朝向走一步，并结束本 tick TURNR 朝向 = R%4（让感知结果直接驱动转向） ADD a R += a CMP a R = (R > a) ? 1 : 0 基因 = 指令数组。变异是替换/插入/删除单条指令，交叉是单点拼接。 没有梯度、没有神经网络、没有外部模型 —— 纯选择压力。
确定性：同一个 seed 重放结果完全一致（xorshift32，每局 seed 由 gen/个体/对手/回合哈希）。先手每 tick 交替，消除抢食偏置。
零依赖、零联网、零 API 调用，file:// 直接打开即可。引擎是独立于 DOM 的纯函数块（ENGINE START/END），可以整段搬进 Node 做批量实验，或者换成 Unity / Three.js 的渲染层。
