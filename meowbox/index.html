喵盒 MeowBox Version History & Notice

一个自己写着用的 Android App：邮箱验证码登录、聊天、好友、朋友圈、公开 API 工具箱。 这个页面放的是它每一次版本改了什么、怎么装、以及必须说清楚的那些事 —— 因为它是个人业余项目，没有备案、没有上架任何应用商店。

最新 0.11.0 页面不提供下载 未办理 ICP / App 备案 未上架应用商店 个人非商业 · 不收费

先说最要紧的三件事

① 这个 App 没有在任何应用商店上架，也没有办理 ICP 备案和 App 备案。 它不是对外经营的产品，只是我自己做、自己用，顺手分享给朋友的技术练习作品。

② 数据存在新加坡的服务器上（Appwrite Cloud），这构成个人信息出境。 我没有做数据出境安全评估，因为不具备申报主体资格。请不要在里面存放任何敏感信息。

③ 服务端没有任何内容审核，也没有端到端加密。 发出去的内容理论上服务端可读。请把它当成一个公开的半成品来用。

v0.9.1 2026-11-08 · code 10
按压手感（这次只有这个，没有新功能）
  • 方块水波纹没了：原来用的是 Material 默认 ripple，它按控件矩形边界绘制，所以在图标、小按钮、心形上戳下去会冒出一个硬邦邦的方块。换成自己画的反馈后，形状跟着控件走 —— 圆形热区得到圆形反馈，条状按钮得到胶囊反馈，全项目再没有直角方块。
  • 圆角按控件比例自适应：原来只按「短边一半」算半径，像「心形＋数字」这种约 40×23 的宽扁节点，半径在宽度上只占 29%，看上去仍是个方片。现在宽高比超过 1.4 就按高度收圆角，趋近胶囊。
  • 真的会「压下去」：按下时整块缩到 0.86~0.96，松开用弹簧弹回，不是线性渐变。缩放走图层变换，不参与布局，不会让周围元素跳动。
  • 极轻触感反馈：只在按下沿触发一次，用系统最轻那一档，不需要任何权限。
  • 红心弹跳加大：幅度改成 1 → 1.38 → 0.94 → 1。原来 1.32 起跳，在 29dp 的心形上肉眼看不出来，点完只觉得「亮了」。
  • 10 处 IconButton 换成自绘版：Material3 的 IconButton 内部写死了 ripple()，根本不读全局设置，所以标题栏的返回/刷新/新建三个图标以前照样是方块。
  • 补齐 11 处零散小按钮：朋友圈的「取消/发布/发送」、表情面板的格子、搭子的「撤回」、联系人的「举报/屏蔽」、我的「取消收藏」、登录页的协议勾选框（这个以前 indication = null，点了完全没有反馈）。
  • 加载中的按钮自动禁用按压：避免连点造成重复请求。
更新检查
  • 修掉了一个假的降级链：原来以为「自定义域 + github.io 默认域」是两个互为备份的源，实测发现 github.io 那个会 301 重定向回 chuyangbz.me —— 两行其实是同一个源，主站 DNS 一挂就两个一起挂，等于没有降级。真正的独立源是 jsDelivr（直接从 GitHub 仓库读，走自己的 CDN，不经过 Pages 的域名和证书链），现在它在第二位。
仍然做不到的（如实写明）
  • 陌生人注册仍未关闭，这是遗留的合规项。
  • 屏蔽仍是纯本机行为，不是服务端拉黑：名单只存在这台手机里，对方不会收到通知，依然能看到你的动态、依然能给你发消息。真正的拉黑需要新建 blocks 表并配读权限规则。
  • 「仅好友」依旧是本机过滤，不是服务端权限。

怎么装

因为这个 App 没有上架商店，安装只能靠 APK 手动进行。下面这套流程是它装到手机上的真实步骤，写出来是为了说明它会遇到什么、为什么遇到，不是让你现在去装。

从已安装的 App 里走「检查更新」下载新包；本页面不提供公开下载入口。
用文件管理器打开它。系统会提示「禁止安装未知来源应用」—— 到设置里给这个文件管理器（或浏览器）打开「安装未知应用」权限，再回来点一次。
安装界面会显示没有应用商店来源、可能提示风险。这是所有未上架 APK 的必然状态。
装好后首次打开，会先看到登录页。必须勾选用户协议和隐私政策才能登录 —— 不勾选按钮是灰的，这是有意为之。
如果只是想看看界面，可以点「先逛逛，不登录」，但发动态、聊天、加好友都需要登录。
升级时如果报「应用未安装」，通常是因为之前的包签名不同。把旧版卸载再装新版即可， 但卸载会清除本地数据（登录状态、签到记录、设置）。 同一个分发包来源的签名是一致的，可以直接覆盖。
