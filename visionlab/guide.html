VisionLab 使用说明

VisionLab 是一个跑在浏览器里的图片识别与标注工作台。双击本地文件，或者打开网页版输入访问密码，就能做三件事：判断图里是什么（图像分类）、找出有几个什么在哪（目标检测）、描出物体的轮廓（实例分割）。

它不依赖后端，也不用安装任何软件。内置模型是 YOLO11n-seg（Ultralytics YOLO11 系列），以 ONNX 格式由 ONNX Runtime Web 在浏览器本地推理，认识 COCO 的 80 类常见物体：人、猫、狗、汽车、杯子、手机、笔记本电脑、苹果、香蕉等。除了你主动填 Key 调用在线 API，图片始终留在本机，断网也能完整使用。

一句话说清边界：它只认识 COCO 80 类。陌生品类不会凭空给出正确答案，通常提示「未识别到 COCO 80 类中的物体」。结果只是模型的猜测，预测和真值分开保存，只有点「采纳为真值」才会改写标注。

一、两种打开方式

方式一：本地文件（推荐用于课堂演示）

双击 VisionLab.html（约 30.7 MB，Edge 或 Chrome 打开）。不需要密码、不需要联网，等状态条显示「YOLO11n-seg 就绪」即可使用。整个程序、模型和演示照片都在这一个文件里，拷到 U 盘、发给别人都能直接打开。

方式二：在线网页

访问 https://chuyangbz.me/visionlab/，输入访问密码后进入。

  1. 首次进入需要下载约 16 MB 的模型数据并在本地解密，进度条走完直接进入工作台。
  2. 勾选「本次会话记住」后，同一个标签页内刷新不用重复输入；关掉浏览器再打开需要重新输入。
  3. 密码由发布者提供。输错只会提示「密码不正确」，可以反复重试，没有次数限制。

网络较慢时首次加载可能需要几分钟，这是 16 MB 数据在下载，不是卡死。之后再进入浏览器已有缓存，通常一两秒就绪。

建议使用较新的 Edge 或 Chrome（Chromium 内核，版本 90 以上）。Safari 16.4+、Firefox 113+ 也能运行；过旧的浏览器会在密码框下方直接提示升级。

两种方式的数据互不相通：本地文件（file://）和在线网页（https://）在浏览器里属于不同来源，各存各的图片库。要长期保存请用「导出完整备份」，再在另一边「导入备份」。

二、界面速览

  • 顶部：三个任务标签（分类 / 检测 / 分割）、「数据概览」、「API 设置」。切换任务不会丢图片和标注。
  • 左侧：导入图片、载入真实样片、摄像头拍照、导入文件夹；搜索框；四种筛选；类别分布；图片缩略图列表。
  • 中间：当前任务名、操作提示和工具按钮；图片按窗口大小自适应显示；下方是模型状态。
  • 右侧：图片信息、真值标签、形状列表、模型预测、质量指标、导出按钮。
  • 底部：状态提示、批量进度、图片数与标注数统计。

三、导入图片

三种入口：导入图片（可多选文件）、导入文件夹（收进整个目录）、载入真实样片（写入内置的 8 张真实照片）。

支持 JPG / JPEG、PNG、WebP，其他格式会被过滤。导入逐张显示进度，某一张失败不会中断整批。每张图会生成最长边 320 像素的缩略图，原图、尺寸、文件名、拍摄时间和标注一起存进浏览器数据库。

内置样片是真实公开照片（苹果、香蕉、人、猫、狗、杯子、汽车、笔记本电脑），来自 CC0 或公有领域，自带分类真值，并预分在 train / val / test 三集里，猫和汽车标记为难例。载入后自动选中第一张并识别一次，缩略图上带「演示」标记，可用「清除演示数据」单独删除。

四、三种任务怎么用

图像分类：选一张图点识别，右侧预测卡显示主体类别、置信度和最多四个候选条形。认同就点「采纳为真值」；不认同就点正确的类别标签。最高分低于 0.30 会提示「判定不确定」，前两名相差不到 0.1 会提示候选接近，建议换主体更单一的照片。

目标检测：识别后出现彩色矩形框，框上标类别和置信度，右侧列出「检测到 N 个目标」。手工补标时在空白处拖拽即可画框，点框选中后可改类别或删除。结果自动过滤：分数低于 0.24 的不要、不到最高分 45% 的不要、同类重叠按 IoU 0.45 抑制，画面最多展示 12 个目标。

实例分割：识别后出现半透明闭合多边形。手工描轮廓时单击加点，双击或按 Enter 闭合，Backspace 撤销最后一点，Esc 取消草稿，少于 3 个点不能闭合。选中后可改类别或删除；模型轮廓提取异常时会退化成由框四角组成的多边形。

五、标注操作

核心原则：模型结果只写进「预测」，只有点「采纳为真值」或手工设置，真值才变化。

  • 画框：检测任务下在空白处拖拽，宽或高不足整图 0.5% 的框会被丢弃。已有框可以点选，但不能拖动改位置，要调整请删掉重画。
  • 缩放：画布随窗口自动缩放；当前版本没有滚轮缩放和平移。
  • 删除标注：选中框或轮廓后按 Delete / Backspace，或点右侧列表的「×」。只删标注，不动图片。
  • 删除图片：每张缩略图右上角有红色「×」，点击并确认后，这张图和它的全部标注一起删除，数据库同步删除，刷新也不会回来，不可撤销。
  • 类别：分类任务点标签即设真值；检测和分割任务点标签是切换「新画形状」的类别，已画好的要在右侧下拉框里改。默认 8 类果蔬：苹果、香蕉、橙子、柠檬、黄瓜、胡萝卜、茄子、青椒。
  • 标签集：输入名称后点「添加类别」，重名会被拒绝；类别保存在本地。模型识别出的 COCO 类别会自动补进列表，自定义类别不会被删。
  • 难例：勾选「标记难例」后缩略图显示徽章，并计入统计。
  • 数据划分：每张图带 train / val / test 字段，新导入默认 train，样片预分三集，缩略图显示「训练 / 验证 / 测试」。界面没有手动改划分或按划分筛选的入口；需要重划分可在导出的 JSON 里改 split，再用完整备份导回。

六、本地识别与 API 识别

本地识别完全离线。没配 Key 时所有识别都走本地：「YOLO 识别」强制本地，「识别当前图」有 Key 时优先走 API，「批量识别」对当前筛选下所有可见图片顺序识别，单张失败不中断。

模型输入固定 640×640：图片按比例缩放、灰边填充，结果再换算回原图。主体太小或只占画面一角容易漏检。入选线 0.24、低置信线 0.30、NMS IoU 0.45 都写在程序里，界面不提供调整。

API 识别（可选，默认关闭）：点「API 设置」，默认服务商是硅基流动，Base URL 为 https://api.siliconflow.cn/v1，模型为 Qwen/Qwen2.5-VL-7B-Instruct，Key 需要自己填。三项都可改，其他兼容 /chat/completions 的服务也能用，支持「测试连接」和「获取模型列表」，超时 60 秒。

隐私提醒：Key 默认只存在内存里，不写进 localStorage 和页面源码，刷新后需要重填；勾选「仅本会话记住 Key」才写入 sessionStorage，关闭标签页即失效。一旦使用 API，图片会以 base64 上传到服务商，处理他人肖像、未成年人照片或未公开资料前请先取得授权。

七、摄像头拍照与实时识别

点「摄像头拍照」会请求相机权限，优先后置摄像头、理想分辨率 1280×960、不采集声音。常见报错会被翻译成中文：权限被拒绝、未检测到摄像头、被其他程序占用、浏览器不支持。

实时识别约每 0.3 秒尝试一帧，上一帧没算完就跳过；帧先缩到长边 480 像素再送模型，画面叠加框或多边形及类别、置信度。模型没就绪时暂用启发式果蔬识别，状态条会明确写「启发式实时」，不冒充 YOLO。底部可以暂停；关闭弹窗会停止所有摄像头轨道。点「拍照识别」会把当前帧存成 JPG（质量 0.92）入库。

网页版的摄像头必须满足两个条件：页面跑在 HTTPS 上（本站已满足），以及你点了浏览器的「允许」。如果按钮无反应，检查地址栏左侧的相机小图标或浏览器设置里的网站权限。

八、数据存在哪里

VisionLab 没有服务器数据库，你的图片和标注全部存在当前浏览器的 IndexedDB（数据库名 visionlab-db，仓库 images），类别表存在 localStorage 的 visionlab.classes.v1。程序不会把你的数据上传到任何地方。

这意味着：

  • 换浏览器、换设备、换电脑，看不到原来那批数据。
  • 清理浏览器「站点数据 / Cookie 和网站数据」会把数据一起清掉，且不可恢复。
  • 同一台电脑上的不同人使用同一个密码进入，看到的仍是各自浏览器里的数据，互不干扰。
  • 重要数据请定期用「导出完整备份（含图片）」留一份到本地。

九、统计与导出

左侧类别分布按图片统计每个类别在真值中出现的次数。「数据概览」显示总图片、已标注、难例、预测覆盖率、类别分布和质量指标；指标只统计真值与预测同时存在的样本，没有可比样本时显示「—」，不是 0。

导出标注 JSON：包含应用名、版本、导出时间、类别表、每张图的元数据与完整真值、预测，以及总数、已标注、难例、预测覆盖率、每类统计、三集数量和质量指标。框是归一化的 x, y, w, h，轮廓是归一化点数组，文件不含图片二进制，适合交作业或交给其他程序读取。

导出完整备份（含图片）：把图片转成 base64 一起打包，可以完整恢复。导入备份会用备份整体替换数据库，不可撤销；文件非法或缺 images 数组时会报错并保留原数据。注意：单独导出的标注 JSON 不能当备份导入。

清除演示数据只删内置样片；清空数据库删除全部内容，需二次确认。

十一、常见问题

输密码一直提示不正确？ 检查大小写和输入法全角状态，密码是纯小写英文；确实忘记就找发布者要。

进度条卡住或提示加载失败？ 多半是网络中断，刷新重试即可。浏览器缓存被禁用（无痕模式）时每次都要重新下载 16 MB，属正常现象。

一直显示「模型加载失败」？ 刷新页面重试；仍失败请换用较新的 Edge / Chrome，并确认网络能正常访问本站。

识别不出来或不准？ 先确认物体属于 COCO 80 类，再看主体是不是太小、太偏、被遮挡或光线太暗。拍大一点、放中间、保证清晰后重试。提示「判定不确定」时不要直接采纳，也可以切到目标检测看看模型在哪些位置有反应。

为什么置信度不能调？ 阈值固定为入选 0.24、低置信 0.30、NMS IoU 0.45，没有滑块，这样不同人、不同电脑的判定标准一致。

摄像头打不开？ 依次排查：浏览器是否允许本站使用相机、系统里是否有摄像头、是否被视频会议或相机程序占用。手机浏览器需要 HTTPS，本站满足条件。

数据会丢吗？ 只存在当前浏览器里，清理站点数据或换设备都会看不到，请用「导出完整备份」留底。

画布能缩放吗？ 当前版本没有滚轮缩放、没有平移、不能拖动已有框，也不支持拖拽文件导入。这些都是「当前版本没有」，不是坏了。

十二、隐私与许可

不使用 API 时，图片只在本机浏览器里解码、显示、标注和推理，不会离开你的电脑；页面除首次加载自身资源外不发起任何外部网络请求。

内置模型是 Ultralytics 的 YOLO11n-seg，YOLO 系列采用 AGPL-3.0 许可：个人学习、研究和非商业用途一般可以直接使用；商业产品、闭源分发或对外提供服务需要遵守开源要求，或向 Ultralytics 购买商业授权。浏览器推理使用 ONNX Runtime Web，许可以其项目说明为准；内置演示照片来自公开图库，标注为 CC0 或公有领域。

你自己导入的照片和标注数据由你自己保管，程序不会自动上传到任何地方。
