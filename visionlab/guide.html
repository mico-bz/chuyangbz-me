VisionLab 使用说明

VisionLab 是一个跑在浏览器里的图片识别与标注工具。双击本地文件，或者打开网页版输入访问密码，就能做三件事：判断图里是什么（图像分类）、找出有几个什么、在哪（目标检测）、描出物体轮廓（实例分割）。

不用装软件，也没有后台服务器。内置模型是 YOLO11n-seg，11.7 MB，用 ONNX Runtime Web 直接在浏览器里推理，认识 COCO 的 80 类常见物体，人、猫、狗、汽车、杯子、手机、笔记本电脑、苹果、香蕉这些都在里面。除了自己填 Key 调在线 API 的情况，图片不会离开本机，断网也能把整套流程走完。

先说清楚它做不到什么。它只认 COCO 的 80 类，拍到没学过的品类，不会给出可靠的新名字，通常提示「未识别到 COCO 80 类中的物体」。给出的结果也只是模型的猜测：预测和真值分开保存，只有点「采纳为真值」才会改动标注。它不负责训练模型。

一、两种打开方式

本地文件：双击 VisionLab.html，约 30.7 MB，用 Edge 或 Chrome 打开。不需要密码，也不用联网。等状态条出现「YOLO11n-seg 就绪」就可以开始。程序、模型和 8 张演示照片都在这一个文件里，拷到 U 盘或者发给同学，双击都能用。

在线网页：访问 https://chuyangbz.me/visionlab/，输入访问密码进入。第一次要下载约 16 MB 数据并在本地解密，进度条走完自动进工作台。网慢的时候可能等上几分钟，那是在下载，不是卡死，让它跑完就行。勾选「本次会话记住」之后，同一个标签页刷新不用重新输入；浏览器关掉再打开还是要输一次。密码输错只提示「密码不正确」，可以一直重试，没有次数限制。

两种方式的数据不互通。本地文件走 file:// 协议，网页版是 https://，浏览器把它们当作两个不同来源，图片库各存各的。要把数据搬过去，先在一边导出完整备份，再到另一边导入。

建议用较新的 Edge 或 Chrome，Chromium 内核 90 以上都没问题。Safari 16.4+、Firefox 113+ 也能跑；版本太旧的话，密码框下面会直接提示升级。

二、界面速览

顶部是三个任务标签（分类、检测、分割），右边还有「数据概览」和「API 设置」。切换任务不会丢图片和标注，随时能来回切。

左侧从上到下依次是导入图片、载入真实样片、摄像头拍照、导入文件夹，然后是搜索框、四种筛选、类别分布和缩略图列表。

中间显示当前任务名、操作提示和工具按钮，图片按窗口大小自适应，下方一行是模型状态。

右侧依次是图片信息、真值标签、形状列表、模型预测、质量指标和导出按钮。最底部一条状态栏，显示进度、图片数量和标注数量。

三、导入图片

三个入口：导入图片可以多选文件，导入文件夹把整个目录收进来，载入真实样片会写入内置的那 8 张真实照片。

支持 JPG、JPEG、PNG、WebP，其他格式会被过滤掉。导入时逐张显示进度，某一张失败不会中断整批处理。每张图会生成一张最长边 320 像素的缩略图，原图、尺寸、文件名、拍摄时间和标注一起存进浏览器数据库。

内置样片是苹果、香蕉、人、猫、狗、杯子、汽车、笔记本电脑各一张，来源是 CC0 或公有领域的公开照片，自带分类真值，也已经预分在 train / val / test 三集里，其中猫和汽车标为难例。载入后会自动选中第一张并识别一次。缩略图上带「演示」标记，不想要了用「清除演示数据」可以单独删掉。

四、三种任务怎么用

图像分类：选一张图点识别，右侧预测卡会显示主体类别、置信度和最多四条候选。认同就点「采纳为真值」，不认同就直接点正确的类别标签。最高分低于 0.30 时会提示「判定不确定」，前两名相差不到 0.1 会提示候选接近，这时候换个主体更单一的照片会更准。

目标检测：识别后画面上出现彩色矩形框，框上标着类别和置信度，右侧列出「检测到 N 个目标」。手工补标时在空白处拖拽就能画框，点一下框可以选中，然后改类别或者删掉。结果会自动过滤：分数低于 0.24 的不要，不到最高分 45% 的不要，同类重叠按 IoU 0.45 抑制，画面上最多留 12 个目标。

实例分割：识别后出现半透明的闭合多边形。手工描轮廓时单击加点，双击或者按 Enter 闭合，Backspace 撤销最后一个点，Esc 取消草稿，少于 3 个点不能闭合。选中后同样可以改类别或删除。模型轮廓提取出问题时，会退化成由框四个角组成的多边形，这是正常的降级处理。

五、标注操作

这里的原则很简单：模型结果只写进「预测」，只有点「采纳为真值」或者自己手工设置，真值才会变。

画框在检测任务下进行，在空白处拖拽即可，宽或高不足整图 0.5% 的框会被丢掉。已有的框能点选，但拖不动位置，要挪只能删了重画。

画布随窗口自动缩放，当前版本没有滚轮缩放和平移。

删标注：选中框或轮廓后按 Delete / Backspace，或者点右侧列表里的「×」。这一步只删标注，不动图片。

删图片：每张缩略图右上角有个红色「×」，点了并确认之后，这张图和它的全部标注一起删除，数据库里也同步删掉，刷新不会回来，不可撤销。只想删标注的话用上面那个办法。

类别：分类任务点标签就等于设真值；检测和分割任务点标签是切换新画形状用的类别，已经画好的要在右侧下拉框里改。默认给了 8 类果蔬，苹果、香蕉、橙子、柠檬、黄瓜、胡萝卜、茄子、青椒。

标签集：输入名称后点「添加类别」，重名会被拒绝，类别存在本地。模型识别出的 COCO 类别会自动补进列表，自定义的类别不会被删。

难例：勾选「标记难例」后缩略图上显示徽章，也会计入统计。

数据划分：每张图都带 train / val / test 字段，新导入的默认 train，样片已经预分好，缩略图上显示「训练 / 验证 / 测试」。界面暂时没有手动改划分的入口，也没有按划分筛选的功能。真要重新划分，可以在导出的 JSON 里改 split，再用完整备份导回来。

六、本地识别与 API 识别

本地识别全程离线。没配 Key 的时候所有识别都走本地：「YOLO 识别」强制本地，「识别当前图」在有 Key 时优先走 API，「批量识别」会把当前筛选下能看到的图片按顺序过一遍，单张失败不影响后面的。

模型输入固定 640×640：图片按比例缩放、灰边填充，结果再换算回原图尺寸。主体太小或者只占画面一个角，容易漏检。入选线 0.24、低置信线 0.30、NMS IoU 0.45 都写在程序里，界面上没有调节入口，这也是为了让不同人、不同电脑的判定标准保持一致。

API 识别是可选的，默认关着。点「API 设置」可以看到默认服务商是硅基流动，Base URL 为 https://api.siliconflow.cn/v1，模型是 Qwen/Qwen2.5-VL-7B-Instruct，Key 需要自己填。这三项都能改，其他兼容 /chat/completions 的服务也能用，界面上有「测试连接」和「获取模型列表」，超时 60 秒。

Key 默认只在内存里，不写 localStorage，也不会出现在页面源码中，刷新就得重填。勾选「仅本会话记住 Key」才会写进 sessionStorage，关掉标签页就失效。要提醒一句：一旦走了 API，图片会以 base64 上传给服务商，处理别人肖像、未成年人照片或者未公开材料之前，先拿到同意。

七、摄像头拍照与实时识别

点「摄像头拍照」会请求相机权限，优先后置摄像头，理想分辨率 1280×960，不采集声音。常见的报错都会被翻译成中文：权限被拒绝、未检测到摄像头、被别的程序占用、浏览器不支持。

实时识别大约每 0.3 秒试一帧，上一帧没算完就跳过这次；帧会先缩到长边 480 像素再送进模型，画面上叠加框或多边形，旁边标类别和置信度。模型还没就绪时会先用启发式的果蔬识别顶着，状态条会明确写「启发式实时」，不会冒充 YOLO。底部可以暂停，关掉弹窗会把所有摄像头轨道一起停掉。点「拍照识别」把当前帧存成 JPG（质量 0.92）入库。

网页版还有一个前提：页面必须跑在 HTTPS 上（本站满足），并且你要在浏览器弹窗里点「允许」。如果点了按钮没反应，去看地址栏左边那个相机小图标，或者浏览器设置里的网站权限。

八、数据存在哪里

VisionLab 没有服务器数据库，图片和标注全都存在当前浏览器的 IndexedDB 里（数据库名 visionlab-db，仓库 images），类别表在 localStorage 的 visionlab.classes.v1。程序不会把数据上传到任何地方。

所以有几件事得有心理准备：换浏览器、换电脑就看不到原来那批数据；清理浏览器的「站点数据」会把它们一起清掉，且恢复不了；同一台电脑上不同人用同一个密码进去，看到的还是各自浏览器里的东西，互不干扰。

重要数据请定期用「导出完整备份（含图片）」在本地留一份。

九、统计与导出

左侧的类别分布按图片统计每个类别在真值里出现的次数。「数据概览」里能看到总图片数、已标注、难例、预测覆盖率、类别分布和质量指标。质量指标只统计真值和预测同时存在的样本，没有可比样本时显示「—」，而不是 0。

导出标注 JSON 会带上应用名、版本、导出时间、类别表、每张图的元数据和完整真值、预测，还有总数、已标注、难例、预测覆盖率、每类统计、三集数量和质量指标。框是归一化的 x, y, w, h，轮廓是归一化点数组。这个文件不含图片二进制，适合交作业或者交给其他程序读。

导出完整备份（含图片）会把图片转成 base64 一起打包，可以完整恢复。导入备份会用备份整体替换数据库，不可撤销；文件不合法或者缺 images 数组时会报错并保留原数据。单独导出的标注 JSON 不能当备份导入，这两者不是一回事。

「清除演示数据」只删内置样片，「清空数据库」删全部内容，需要二次确认。

十一、常见问题

输密码一直提示不正确？先看大小写和输入法是不是全角状态，密码是纯小写英文。真忘了就找发布者要。

进度条卡住或者提示加载失败？多半是网络断了，刷新重试。如果开着无痕模式，浏览器不给缓存，每次都要重新下 16 MB，这是正常的。

一直显示「模型加载失败」？先刷新一次；还不行就换较新的 Edge 或 Chrome，顺便确认网络能正常访问本站。

识别不出来或者不准？先看物体在不在 COCO 80 类里，再看主体是不是太小、太偏、被遮挡或者光线太暗。拍大一点、放中间、保证清晰再试。提示「判定不确定」时别直接采纳，也可以切到目标检测看看模型在哪些位置有反应。

为什么置信度不能调？阈值固定为入选 0.24、低置信 0.30、NMS IoU 0.45，界面没有滑块，这样大家的判定标准才一致。

摄像头打不开？按顺序排查：浏览器有没有允许本站用相机、系统里有没有摄像头、是不是被视频会议或者相机程序占着。手机浏览器要求 HTTPS，本站满足。

数据会丢吗？只存在当前浏览器，清站点数据或者换设备都会看不到，记得导出完整备份留底。

画布能缩放吗？当前版本没有滚轮缩放、没有平移、不能拖动已有的框，也不支持拖拽文件导入。这些都是「目前没有」，不是坏了。

十二、隐私与许可

不用 API 的时候，图片只在本机浏览器里解码、显示、标注和推理，不会离开电脑；页面除了首次加载自身资源，不发起其他外部请求。

内置模型是 Ultralytics 的 YOLO11n-seg，YOLO 系列采用 AGPL-3.0 许可：个人学习、研究和非商业用途一般可以直接用，商业产品、闭源分发或者对外提供服务则要遵守开源要求，或者向 Ultralytics 购买商业授权。浏览器推理用的 ONNX Runtime Web，许可以它自己的项目说明为准。内置演示照片来自公开图库，标注为 CC0 或公有领域。

自己导入的照片和标注数据由自己保管，程序不会自动上传。
